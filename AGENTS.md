# AGENTS.md

Guidance for coding agents working on **nowhere**, a personal travel-guide site
(Next.js 16 App Router + React 19 + TypeScript + Tailwind CSS 4). See `README.md` for the overview.

## Commands

```bash
yarn
yarn dev               # dev server on :3000 (Turbopack)
yarn typecheck         # next typegen + tsc --noEmit
yarn lint              # oxlint
yarn format:check      # prettier
yarn build             # next build
yarn icons             # re-render home-screen icons from app/icon.svg
```

The package manager is **yarn** (classic, `yarn.lock`): never use npm or add a `package-lock.json`.

Before considering a change done, run
`yarn typecheck && yarn lint && yarn format:check && yarn build`.
There is no test suite yet.

## Next.js specifics

- App Router only (`app/`). No `src/` dir; import alias `@/*` → repo root.
- `cacheComponents` is on (`next.config.ts`). Dynamic routes need `generateStaticParams`
  returning at least one param; `params` is a Promise — `await` it.
- Use the global route types `PageProps<'/route'>` / `LayoutProps<'/route'>` (generated by
  `next typegen`).
- Server Components by default. Add `'use client'` only where browser APIs or state are needed
  (today: `components/PrintPlates.tsx`, `components/WorldMap.tsx`). Keep client components at the
  leaves; pages stay server-side and pass plain data down.
- Phosphor icons in Server Components: `import { XIcon } from '@phosphor-icons/react/ssr'`
  (use the `…Icon` names; the bare names are deprecated). Use `weight="duotone"`, except glyphs
  whose duotone layer is a filled box (`Plus`, `Minus`): those use the default `regular` weight.
- Fonts via `next/font/google` in `app/layout.tsx` (exposed as `--font-source-serif`); never add a
  Google Fonts `<link>`.
- Tailwind 4 runs through the `@tailwindcss/turbopack` loader configured in `next.config.ts`
  (no PostCSS config).
- Metadata via `export const metadata` / `generateMetadata`; titles use the `%s — Nowhere` template.
- Icons: `app/icon.svg` is the favicon and the source of the home-screen icons
  (`app/apple-icon.png`, `public/icons/icon-*.png`, listed in `app/manifest.ts`). Those PNGs are
  generated: after changing `app/icon.svg`, run `yarn icons`.

## Code style

- Prettier: no semicolons, single quotes, trailing commas, 100-column width, Tailwind classes
  sorted by `prettier-plugin-tailwindcss`. 2-space indent, LF.
- UI strings live in `i18n/it.json`, never inline: `import { t, format } from '@/i18n'`, then
  `t.map.searchPlaceholder` or `format(t.guide.trip.citiesOf, { name })` for `{placeholders}`.
  Keys are typed from the JSON. Guide prose is content, not UI: it stays in `content/guides/`.
  Use `locale` from `@/i18n` for `lang`, `localeCompare`, `Intl` and similar. Image alt texts
  are UI strings too. Per guide, `guides.<slug>` holds `toc` (index labels and dates, reused as
  the matching section titles), `regions` (place names, used by `places`, index and `Region`) and
  `alt`; captions and prose stay in content.
- Asset file names are English and kebab-case (`coat-of-arms.png`, `flag.svg`, `map.png`).
- Pages/layouts use `export default`; shared components use named exports with props typed via a
  local `type`.
- Use `next/link` for internal links.
- Everything in the repo is in English: docs, code comments, identifiers, commit messages.
  Exceptions: user-facing UI copy (Italian), and place names in guides — region and city enum
  members/values keep their Italian names (`Romania.Valacchia = 'valacchia'`). Refer to UI
  features by an English name in code and comments (e.g. "trip filter", shown as "Il tuo viaggio").

## Design system (Broadsheet)

The source of truth is the claude.ai/design project **Nowhere**
(`https://claude.ai/design/p/71e00691-2bb5-4596-89b0-0be5888e925e`), design system
`_ds/broadsheet-419caee6-…`. Local ports:

- `styles/theme.css` — tokens as a Tailwind `@theme`. **Change the look here only.**
- `styles/broadsheet.css` — component classes (`.btn`, `.card`, `.tag`, `.nav`, `.table`,
  `.dialog`, `.input`, `.seg`, `.radio`) and print treatments (`.halftone`, `.cmyk`,
  `.cmyk-head`, `.cmyk-num`). Loaded in the `components` layer so utilities can override it.
- `lib/printPlates.ts` — port of `print-plates.js`: mounts the `#sep-*` SVG filters and the
  press driver that publishes `--press-nx` / `--press-ny` on `:root`. Mounted once by
  `components/PrintPlates.tsx` in the root layout.
- `components/Logo.tsx` — port of `NowhereLogo.dc.html`. Design variants map as
  Orizzontale→`horizontal`, Verticale→`vertical`, Simbolo→`symbol`, Parola→`wordmark`;
  only the Quadricromia tone is used (Inchiostro is not ported). Keep geometry (viewBoxes, dot
  radii, plate offsets) identical to the design file.
- `components/PlateText.tsx` — wrapper for `.cmyk-head` / `.cmyk-num`.

Rules:

- Use only design tokens. Tailwind's default colors are disabled (`--color-*: initial`); do not
  add hex values or arbitrary colors in components.
- Spacing scale is 5px per step (`p-4` = 20px).
- Structure pages with type scale and white space, not borders/boxes. `.card` is for discrete
  items only; avoid `.hr`.
- `process-yellow` is only for print treatments, never interface accents. The one text use is
  the date highlighter in guide content (`<D>` / `.date-mark`), as in the design.
- Plate constructions keep the real text in the `.paper` span; plate copies are `aria-hidden`.
- Respect `prefers-reduced-motion` and coarse pointers (the press driver already stands down).

When updating from the design project, diff the remote `styles.css` / `.dc.html` against the
local ports and change them surgically; do not paste the design runtime (`support.js`,
`_ds_bundle.js`) into the app.

## Content

- Guides are registered in `data/guides.ts`. `countryId` is the ISO 3166-1 numeric code
  (matches world TopoJSON feature ids); `at` is `[lon, lat]`; `status` is `ready | draft`.
- Routes: `/` home (full-screen map + footer), `/guide/[slug]` guide, `not-found.tsx` 404 (renders
  `SiteHeader` itself). There is deliberately no `/guide` index page: the map is the index.
- Guides: port of `Guida Romania - Sito.dc.html`. Content is TSX in `content/guides/<slug>.tsx`
  built from `components/guide/content.tsx` (server) and `<Only>`/`<Unless>` from
  `components/guide/trip.tsx` (client). Keep content files free of styling: if something new is
  needed, add a primitive to the kit. Place ids are a per-guide string `enum` (see
  `romania.tsx`): type the content as `GuideContent<Enum>` and alias `Only`/`Unless` as
  `Gate<Enum>`; never write place ids as bare strings. Enum values are persisted in localStorage,
  so don't rename them after publishing. The trip filter state is localStorage
  `guida-<slug>-off` read via `useSyncExternalStore` (server snapshot = everything on), so SSR
  always renders the full text. Images go through `publicAsset()` (`lib/assets.ts`): missing
  files render a placeholder instead of a broken image.
- Cover ink: `coverInk` in a guide's content sets the color of the country name _and_ the nowhere
  logo on the cover (`<GuideCover ink>` → `<LogoBadge ink>` → `<Logo ink>`). They must always be
  the same color: don't color one without the other.
- Design deviations on guide pages: the upper part of the design's guide footer (recap, chapters,
  "Torna su") is a closing section (`GuideOutro`), then comes the site footer; the
  mobile menu's "Tutte le guide" is "Torna alla mappa", and the design's `showRefs` (region tags
  on content) and "Dai miei appunti" map variant are not ported.
- One footer for the whole site (`components/SiteFooter.tsx`), on the home and on every guide. It
  follows the home design but replaces its guide links and "Identità visiva" link with the credit
  "Realizzato da petomis" → https://www.petomis.com.
- The home map (`components/WorldMap.tsx`) is a port of `Nowhere - Home.dc.html`: d3 owns the SVG
  (projection, zoom, country paths), React owns the overlays. d3 handlers read React state through
  refs. Only guides with `status: 'ready'` are passed to the map. Deviation: the design's light-blue
  background is not ported: sea and background are `bg`, as the guides and the status bar.
- `public/data/world-50m.json` is world-atlas `countries-50m` minus Antarctica, with Italian names
  in `properties.n` — identical to the design's `assets/mondo-50m.json`. Don't run prettier on it
  (`.prettierignore`).
